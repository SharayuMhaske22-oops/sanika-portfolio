# Sanika Umak — Engineering Portfolio

Responsive single-page portfolio website based on the resume provided.

## Files
- `index.html` — content and sections
- `style.css` — responsive design
- `script.js` — mobile navigation and current year
- `README.md` — these instructions

## Preview locally
Extract the ZIP and open `index.html` in a modern browser. An internet connection is needed for the Google Fonts used in the design.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `sanika-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root (not inside an extra nested folder).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for the published link to appear on the Pages screen.
